# Italian (it) — style brief

Register: **tu** (informal singular); never "Lei" as the polite form, never "voi".
Tone: infinitives for buttons and menu actions ("Salva" for short buttons is fine; "Apri in una nuova scheda" for menus).
Quotes: «…» or "…". Ellipsis: … Accented capitals (È).
Plural: one/other (many is not required). "{n} pagina" / "{n} pagine".
Terminology: libreria (library), volume, pagina, overlay (keep), fumetto/nuvoletta (speech balloon → "nuvoletta"), traduzione, impostazioni (settings), cartella, scheda (tab), file.

Examples
- "Open in New Tab" → "Apri in una nuova scheda"
- "Get Full Translation" → "Traduci tutto il volume"
- "Page {page} of {total}" → "Pagina {page} di {total}"
- "Are you sure you want to delete <em>{name}</em>?" → "Vuoi davvero eliminare <em>{name}</em>?"
- "Long-press any box to reposition or resize it." → "Tieni premuto un riquadro per spostarlo o ridimensionarlo."
