# Brazilian Portuguese (pt-BR) — style brief

Register: **você** (never "tu"). Brazilian vocabulary only: arquivo (not ficheiro), tela (not ecrã), usuário (not utilizador), mouse (not rato), configurações.
Tone: imperatives for buttons ("Salvar", "Cancelar"), infinitives for menu actions ("Abrir em nova aba").
Quotes: "…". Ellipsis: … Decimal comma.
Plural: one/other (many is not required). "{n} página" / "{n} páginas".
Terminology: biblioteca (library), volume, página, sobreposição (overlay box), balão (speech balloon), tradução, configurações (settings), pasta, aba (tab), arquivo.

Examples
- "Open in New Tab" → "Abrir em nova aba"
- "Get Full Translation" → "Traduzir o volume inteiro"
- "Page {page} of {total}" → "Página {page} de {total}"
- "Are you sure you want to delete <em>{name}</em>?" → "Tem certeza de que quer excluir <em>{name}</em>?"
- "Long-press any box to reposition or resize it." → "Toque e segure uma caixa para movê-la ou redimensioná-la."
