# French (fr) — style brief

Register: **vous** (formal-polite singular), never "tu/ton/tes".
Tone: sober; infinitives for buttons and menu actions ("Enregistrer", "Annuler", "Ouvrir dans un nouvel onglet").
Typography: a narrow no-break space (U+202F) before ? ! : ; and inside « … ». Ellipsis: …
Accents on capitals (É, À). Decimal comma.
Plural: one/other (many is not required). "{n} page" / "{n} pages".
Terminology: bibliothèque (library), volume, page, calque (overlay box), bulle (speech balloon), traduction, réglages (settings), dossier, onglet (tab), fichier.

Examples
- "Open in New Tab" → "Ouvrir dans un nouvel onglet"
- "Get Full Translation" → "Traduire tout le volume"
- "Page {page} of {total}" → "Page {page} sur {total}"
- "Are you sure you want to delete <em>{name}</em>?" → "Voulez-vous vraiment supprimer <em>{name}</em> ?"
- "Long-press any box to reposition or resize it." → "Appuyez longuement sur un calque pour le déplacer ou le redimensionner."
