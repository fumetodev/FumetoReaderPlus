# German (de) — style brief

Register: **du** (informal singular), lowercase "du/dein". Never "Sie/Ihnen/Ihr" for the reader.
Tone: concise, technical-neutral; imperatives for buttons ("Speichern", "Abbrechen"), infinitive for menu actions is acceptable ("Seite neu übersetzen").
Nouns capitalised; compound nouns joined ("Übersetzungs-Overlay" → prefer "Übersetzungsoverlay" only when readable, otherwise hyphenate).
Quotes: „…“. Ellipsis: … (single character). Decimal comma; thousands with a thin space or point.
Plural: one/other. "{n} Seite" / "{n} Seiten".
Terminology: Bibliothek (library), Band (volume — a comic volume), Seite (page), Overlay (overlay box), Sprechblase (speech balloon), Übersetzung, Einstellungen, Ordner, Tab (keep "Tab" for the app's Tabs screen), Lesezeichen.

Examples
- "Open in New Tab" → "In neuem Tab öffnen"
- "Get Full Translation" → "Komplett übersetzen"
- "Page {page} of {total}" → "Seite {page} von {total}"
- "Are you sure you want to delete <em>{name}</em>?" → "Möchtest du <em>{name}</em> wirklich löschen?"
- "Long-press any box to reposition or resize it." → "Halte ein Feld gedrückt, um es zu verschieben oder seine Größe zu ändern."
