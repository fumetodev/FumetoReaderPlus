# Indonesian (id) — style brief

Register: **Anda** (capitalised) for the reader; never "kamu/kau/engkau". Standard formal Indonesian (baku), short sentences.
Tone: imperatives for buttons ("Simpan", "Batal"), verb phrases for menu actions ("Buka di tab baru").
Ellipsis: … Quotes: "…"
Plural: Indonesian has no grammatical plural — only "other" is used; never repeat the noun ("halaman", not "halaman-halaman") after a number.
Terminology: pustaka (library), volume, halaman (page), lapisan (overlay box), balon (speech balloon), terjemahan, pengaturan (settings), folder, tab, berkas (file).

Examples
- "Open in New Tab" → "Buka di tab baru"
- "Get Full Translation" → "Terjemahkan seluruh volume"
- "Page {page} of {total}" → "Halaman {page} dari {total}"
- "Are you sure you want to delete <em>{name}</em>?" → "Yakin ingin menghapus <em>{name}</em>?"
- "Long-press any box to reposition or resize it." → "Tekan lama sebuah kotak untuk memindahkan atau mengubah ukurannya."
